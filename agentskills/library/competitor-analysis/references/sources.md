# 来源可信度分级与引用格式（L3 参考资源）

## 分级

| 级别 | 判据 | 是否可作结论依据 |
|---|---|---|
| A | 官方站点 / 官方公告 / 招股书 / 标准文本 | ✅ 可直接引用 |
| B | 权威媒体、行业研报（有署名与日期） | ✅ 需交叉验证 |
| C | 社区帖子、二手转载、无日期页面 | ⚠️ 仅作线索，需升到 A/B |
| D | 无法访问 / 反爬壳 / 与查询无关 | ❌ 不得引用，如实标注未获取 |

## 引用格式

每条结论后附 `[来源标题](URL)（抓取时间 YYYY-MM-DD，级别 A/B/C）`。
搜索失败写 `（本次联网检索不可用：原因）`，**绝不编造 URL 或日期**。

## 与平台治理的关系

- 出域：引用 KB 条目或外发目标时，须过 `governance.kb_control` 出域审批门
  （confidential 未批准 fail-closed 拒绝）。
- 密钥：产出过 `scanner` 密钥检测 + `governance.content_guard` 后置校验，
  命中高危如实挂起 needs_human，不偷偷删。
